# AI辅助开发与作品说明

本项目开发中使用 AI 辅助阅读规则、编写代码、整理文档、构造工程测试和检查界面。默认运行方式为本机离线规则评估；judge.py 目前仅完成本机模拟接口测试，未据此声称真实外部模型联调成功。

公开训练参考标注只用于开发比较，运行评估不读取标注文件。官方验证集没有专家归因，因此没有可报告的验证集准确率。程序生成的解释和结论不等同于专家审定；参赛者需要核对关键例子、理解规则并对提交材料负责。

GitHub调研用于学习设计思路，未将所研究仓库源码作为项目依赖。Python部分采用标准库运行；前端图表内置Chart.js 4.6.1（MIT许可，见CHART_LICENSE.md），无需联网加载。真实企业接入、模型真实联调和隐藏测试成绩均不在当前已验证成果中。

公开开票演示与顾问演示均为独立合成输入，只用于展示和开发测试。官方受限原始资料、轨迹衍生报告、密钥、缓存和个人报名信息不在公开仓库中提供。
