# 公开仓库的数据边界

本仓库公开项目实现、测试源码与独立合成演示。原参赛工作目录保留在作者本机，公开仓库使用独立目录整理。

## 可以在仓库中找到

- 评测核心、报告模板、本机服务、可选模型接口。
- 自包含合成测试，以及需要用户自备官方输入的测试入口。
- `examples/invoice_demo.py` 独立编写的两个开票任务和 A/B 轨迹。
- `examples/advisor_demo.py` 独立编写的知识顾问示例。
- 第三方 Chart.js 文件及其 MIT 许可声明。

独立合成示例没有读取、变换或删改官方轨迹。演示中的客户、金额、运行记录均为虚构，只用于说明程序行为。

## 不在公开仓库中提供

赛事官方原始输入、参考标注、官方 Schema、校验脚本、参赛提交包、官方轨迹衍生报告、录屏、截图、真实密钥、本机模型缓存、历史开发输出和个人报名材料。

需要复跑官方测试时，应自行通过授权渠道取得文件，再以 `TRACEGUARD_DATA_DIR` 或命令行 `--data-dir` 指定本地路径。这些文件不应提交到公共仓库。

## 上传自己的数据前

运行 `evaluate` 生成的 HTML 报告会嵌入原始输入。共享报告等于共享相应轨迹，请先确认数据可公开；模型辅助复核也会将所选轨迹发往配置的端点。

`artifacts/`、`output/`、`dist/`、模型缓存和环境变量文件默认忽略。Git 忽略规则仅是辅助，不能替代提交前核对。
